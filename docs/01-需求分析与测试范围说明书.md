## 1. 文档目的

本文档从测试视角对 BlogSystem 博客系统的需求进行梳理与拆解，明确测试范围、业务规则与测试需求，作为测试计划、测试用例设计与缺陷跟踪的输入基线。

## 2. 项目概述

BlogSystem 是一个个人博客系统，提供用户注册登录、博客发布/编辑/删除（逻辑删除）、管理员上下架管理等核心能力。前端为原生 HTML + jQuery + editor.md（Markdown 编辑器），后端提供 RESTful 接口，采用 JWT 做登录态鉴权，登录拦截器统一拦截受保护接口。

## 3. 功能需求清单

### 3.1 用户模块

| 编号 | 功能 | 接口 | 鉴权 | 说明 |
|---|---|---|---|---|
| FR-USER-01 | 用户注册 | POST /user/register | 无需 | 用户名 4~20 字符、密码 6~20 字符、需确认密码一致；用户名唯一；密码加盐哈希存储 |
| FR-USER-02 | 用户登录 | POST /user/login | 无需 | 校验用户名存在、密码正确，成功后签发 JWT（24h 有效） |
| FR-USER-03 | 查询用户信息 | GET /user/getUserInfo?userId= | 需登录 | 返回用户信息及该用户博客数量 |
| FR-USER-04 | 根据博客查作者 | GET /user/getAuthorInfo?blogId= | 需登录 | 通过博客 id 反查作者信息 |

### 3.2 博客模块

| 编号 | 功能 | 接口 | 鉴权 | 说明 |
|---|---|---|---|---|
| FR-BLOG-01 | 博客列表 | GET /blog/getList | 需登录 | 仅返回**已上架（published_status=1）且未删除（delete_flag=0）**的博客，按 id 倒序 |
| FR-BLOG-02 | 博客详情 | GET /blog/getBlogDetail?blogId= | 需登录 | 仅查询未删除博客，blogId ≥ 1 |
| FR-BLOG-03 | 新增博客 | POST /blog/add | 需登录 | 标题非空且 ≤200 字符、内容非空；初始状态上架 |
| FR-BLOG-04 | 更新博客 | POST /blog/update | 需登录 | 仅**作者本人**可更新；标题/内容校验同上 |
| FR-BLOG-05 | 删除博客 | POST /blog/delete?blogId= | 需登录 | 仅**作者本人**可删除；**逻辑删除**（delete_flag=1），删除后列表/详情不可见 |
| FR-BLOG-06 | 管理员列表 | GET /blog/adminList | 管理员 | 返回全部未删除博客（含下架） |
| FR-BLOG-07 | 切换上下架 | POST /blog/togglePublish?blogId= | 管理员 | 已上架→下架、已下架→上架 |

### 3.3 鉴权与权限规则（业务规则）

| 编号 | 规则 |
|---|---|
| BR-01 | 除 `/user/login`、`/user/register` 外，所有 `/user/**`、`/blog/**` 接口必须携带有效 token（请求头 `user_token` 或兼容头 `userToken`），缺失/无效/过期返回 HTTP 401 |
| BR-02 | token 由 JWT 签发，密钥可配置（`blog.jwt.secret`，支持环境变量 `BLOG_JWT_SECRET` 覆盖），过期时间默认 24h |
| BR-03 | 新增/更新/删除博客需从 token 解析出 userId，解析失败视为登录失效 |
| BR-04 | 更新/删除博客时校验"当前用户 == 博客作者"，否则拒绝（无权编辑/删除） |
| BR-05 | 管理端接口（adminList、togglePublish）校验 token 中用户名为 `admin`，否则拒绝（无管理员权限） |
| BR-06 | 删除为逻辑删除，被删除博客从所有对外查询中消失 |
| BR-07 | 列表接口只展示已上架博客，下架博客仅在管理端可见 |
| BR-08 | 博客标题 ≤200 字符、非空；内容非空（后端校验注解 + 服务层双重校验） |
| BR-09 | 用户名 4~20 字符、密码 6~20 字符、注册需两次密码一致（参数校验注解） |
| BR-10 | 注册时用户名唯一性校验**包含已逻辑删除用户**（防止复用用户名） |

## 4. 非功能需求

| 类型 | 需求/关注点 |
|---|---|
| 性能 | 博客列表全量查询无分页，数据量大时存在性能风险（对应缺陷 BUG-06） |
| 安全 | 密码不得以明文/哈希形式写入日志（BUG-04 已修复）；JWT 密钥不得硬编码（BUG-05 已修复）；登录无频率限制（BUG-08 遗留）；博客内容无 XSS 过滤（BUG-11 遗留） |
| 兼容性 | 前端页面基于 jQuery 3.6.4，需在主流浏览器（Chrome/Edge/Firefox）验证 |
| 易用性 | 错误响应缺少细分业务错误码，用户提示不够友好（BUG-03 部分修复） |

## 5. 接口需求清单（测试追溯基线）

| # | 方法 | 路径 | 入参 | 鉴权 | 关联功能 |
|---|---|---|---|---|---|
| 1 | POST | /user/register | UserRegisterRequest JSON | 无 | FR-USER-01 |
| 2 | POST | /user/login | UserLoginRequest JSON | 无 | FR-USER-02 |
| 3 | GET | /user/getUserInfo | userId | 登录 | FR-USER-03 |
| 4 | GET | /user/getAuthorInfo | blogId | 登录 | FR-USER-04 |
| 5 | GET | /blog/getList | - | 登录 | FR-BLOG-01 |
| 6 | GET | /blog/getBlogDetail | blogId | 登录 | FR-BLOG-02 |
| 7 | POST | /blog/add | BlogInfoResponse JSON | 登录 | FR-BLOG-03 |
| 8 | POST | /blog/update | BlogInfoResponse JSON | 登录 | FR-BLOG-04 |
| 9 | POST | /blog/delete | blogId | 登录 | FR-BLOG-05 |
| 10 | GET | /blog/adminList | - | 管理员 | FR-BLOG-06 |
| 11 | POST | /blog/togglePublish | blogId | 管理员 | FR-BLOG-07 |

统一响应结构：成功 `{"code":200,"data":...}`；失败 `{"code":-1,"errMsg":"..."}`；参数校验失败 HTTP 400；未登录/登录失效 HTTP 401。

## 6. 测试需求分析

| 功能点 | 测试关注点 | 优先级 |
|---|---|---|
| 注册 | 参数合法性（等价类/边界值）、用户名唯一、密码一致性、重复注册 | P1 |
| 登录 | 成功/用户不存在/密码错误、token 签发正确性、错误提示 | P1 |
| 博客 CRUD | 正常流、参数校验、作者权限、逻辑删除、状态流转 | P1 |
| 鉴权 | 无 token/无效/过期/篡改 token、管理员权限矩阵 | P1 |
| 管理端 | 上下架流转、列表差异（含下架）、非管理员拒绝 | P1 |
| 用户信息 | 正常查询、不存在 id、博客数统计 | P2 |
| UI 流程 | 注册→登录→写博客→详情→编辑→删除；管理员上下架（Selenium） | P2 |
| 安全 | XSS 注入、SQL 注入尝试、敏感信息泄露 | P2 |
| 兼容性 | Chrome/Edge 页面功能 | P3 |

## 7. 测试范围界定

**纳入测试范围**：上述全部接口的功能、参数校验、鉴权、权限、业务规则、主要 UI 流程、安全关注点。

**不纳入本次范围**：数据库性能调优、并发压测（仅做风险评估）、代码覆盖率度量（未接入 JaCoCo，列为改进项）、移动端适配。
