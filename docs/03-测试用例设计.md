# 03 测试用例设计

| 项目 | 内容 |
|---|---|
| 文档编号 | BS-TEST-DOC-03 |
| 被测系统 | BlogSystem 博客系统 v0.0.1 |
| 编写人 | 测试开发工程师 |
| 编写日期 | 2026-08 |
| 用例总数 | 90（自动化用例：JUnit5 单元测试 11 条 + Selenium UI 自动化 6 条） |

## 1. 设计方法说明

| 方法 | 说明 |
|---|---|
| 等价类划分 | 对输入域划分有效/无效等价类，每类取代表值 |
| 边界值分析 | 关注边界两侧取值（如标题 199/200/201、用户名 3/4/20/21） |
| 判定表 | 权限矩阵、状态流转等多条件组合 |
| 场景法 | 从用户视角串联完整业务流程 |
| 错误推测 | 依据经验与代码审查推测易出错点（空值、篡改、重复、不存在等） |

## 2. 用例编号规则

`TC-<模块>-<序号>`：REG 注册 / LOG 登录 / UINF 用户信息 / LIST 列表 / DET 详情 / ADD 新增 / UPD 更新 / DEL 删除 / ADM 管理端 / AUTH 鉴权 / UI UI 流程 / SEC 安全。

优先级：P0 阻塞级 / P1 重要 / P2 一般 / P3 低。
